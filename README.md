# Greek NL2SQL για βιομηχανική τηλεμετρία

Κώδικας μεταπτυχιακής διπλωματικής εργασίας.

Η εργασία αφορά την πρόσβαση σε βιομηχανικά δεδομένα με φυσική γλώσσα. Ο χρήστης κάνει ερωτήσεις
στα ελληνικά, χωρίς να γνωρίζει SQL ή τη δομή της βάσης. Τα δεδομένα είναι χρονοσειρές από μηχανές
σε PostgreSQL: μετρήσεις αισθητήρων, δυαδικές ενδείξεις κατάστασης (flags, π.χ. ανωμαλία ή ανάγκη
συντήρησης), κατηγορικά πεδία (τύπος μηχανής, τύπος σφάλματος) και εκτιμώμενοι δείκτες (κίνδυνος
διακοπής λειτουργίας, υπολειπόμενη ωφέλιμη ζωή).

Το σύστημα χρησιμοποιεί τοπικά γλωσσικά μοντέλα μέσω Ollama, ώστε τα δεδομένα να μη φεύγουν από
την εγκατάσταση. Η ροή έχει δύο βήματα: το μοντέλο γράφει ένα ερώτημα SQL, το σύστημα το ελέγχει
και το εκτελεί μόνο για ανάγνωση, και στη συνέχεια το μοντέλο γράφει την απάντηση στα ελληνικά.
Όπου ταιριάζει, επιστρέφεται και γράφημα. Υποστηρίζονται ερωτήσεις συνέχειας μέσα στην ίδια
συζήτηση.

Η γνώση για τη συγκεκριμένη βάση (τι σημαίνει κάθε στήλη, ελληνικά συνώνυμα, κανόνες,
παραδείγματα) βρίσκεται σε ένα αρχείο ρυθμίσεων και όχι στον κώδικα, οπότε το σύστημα μπορεί να
μεταφερθεί σε άλλη βάση χωρίς αλλαγές στον κώδικα.

Για την αξιολόγηση φτιάχτηκε ένα σύνολο ελληνικών ερωτήσεων με σωστό SQL αναφοράς, σε διάφορες
κατηγορίες δυσκολίας. Συγκρίθηκαν τοπικά μοντέλα με βάση το αν το αποτέλεσμα του ερωτήματος είναι
σωστό. Δύο επιπλέον πειράματα εξετάζουν βάση με μη περιγραφικά ονόματα στηλών, όπως σε συστήματα
SCADA, και την επίδραση της γλώσσας (ελληνικά ή αγγλικά).

## Δομή

- `nl2sql-api/`: backend (FastAPI). `domain.yaml` είναι η περιγραφή της βάσης (στήλες, συνώνυμα,
  κανόνες, παραδείγματα). Για άλλη βάση αλλάζει μόνο αυτό το αρχείο.
- `nl2sql-ui/`: web εφαρμογή συνομιλίας.
- `benchmark/`: ερωτήσεις αξιολόγησης με SQL αναφοράς και το script που τις τρέχει.
- `benchmark/tb/`, `benchmark/lang/`: δύο επιπλέον πειράματα (μη περιγραφικά ονόματα στηλών τύπου SCADA,
  ερωτήσεις στα αγγλικά).

## Εκτέλεση

Χρειάζονται Docker, NVIDIA GPU και τα δεδομένα στον πίνακα `factory_telemetry_fixed` της βάσης
`iot_staging` (δεν περιλαμβάνονται στο repo).

```bash
cp .env.example .env                  # και βάλτε κωδικό
docker network create shared-services
docker compose up -d
docker exec ollama ollama pull qwen2.5-coder:14b
```

UI: http://localhost:5174 · API: http://localhost:8001
